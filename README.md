# HAM Particles Editor
This is a set of tools meant to help make visual effects with HAM particles easier.

It would have not existed if not Stage Flight, an amazing project that connect a lot of amazing creatures who make cool stuff!

## Usage
Everything works inside Unity Editor. We do not compile this Project into native application as there's no control over that. YET.
To adjust stuff you can play around with sliders in shaders for Color,Depth,XYZBias or edit them directly.
Once you start playmode in Unity Editor, it will output a 1920x1080 texture through Spout2.

## Dependencies
This project uses dependencies such as:
- [VivifyTemplate](https://github.com/Swifter1243/VivifyTemplate) by Swifter1243
- [CRT2D](https://github.com/OwenTheProgrammer/The-Shader-Grimoire) by OwenTheProgrammer
- [KlakSpout](https://github.com/keijiro/KlakSpout) by keijiru

You do not need to install them manually. They are located in the source project itself.

## Installation
Clone main repository
```bash
git clone https://github.com/u-Kotovsky/HAMParticlesEditor.git
```
Open the project via Unity Hub and you're set!
